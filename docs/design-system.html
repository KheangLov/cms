The visual direction for the whole CMS — admin dashboard (Vuetify) and public site (Tailwind) alike — built from one shared token source, per CMS_BUILD_PROMPT.md §11. Glassmorphism

Frosted panels only read as "glass," not just "blurry," when they sit on a gradient or busy ground and keep a visible translucent border.

Gradient usage

Used deliberately, not everywhere — body text, data tables, and form fields stay flat so the gradient keeps its impact.

Typography

Manrope for Latin UI and body text; Kantumruy Pro for Khmer — chosen over the generic Noto Sans Khmer default because its x-height and weight actually sit close to Manrope, instead of looking visually mismatched next to it.

Dark mode

Not a token exercise — a real, persisted, three-state feature. Use the switch at the top of this page; it drives the exact same data-theme mechanism the real app uses.

  • System (default) — follows prefers-color-scheme.
  • Light / Dark — explicit override, persisted to localStorage for anonymous visitors and to User.theme_preference for logged-in users, so it follows them across devices.
  • Vuetify's active theme (emberLight / emberDark) and the Tailwind public site's CSS custom properties flip together from one source — nothing drifts between the two halves of the app.
